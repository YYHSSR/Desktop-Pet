# 鲸鱼娘便携版

双击同目录的 `dsh-pet-standalone-webm-chat.exe` 启动桌宠。
请保留整个文件夹，包括 `_internal`，移动时一起移动。

- 右键桌宠第一行“请点击”：播放回应动作，弹出随机卡通图片气泡。
- 右键桌宠：选择动作、角色、大小，或打开桌宠设置。
- 右键系统托盘中的鲸鱼娘图标：显示／隐藏桌宠、鼠标穿透、开机自启、退出。
- 开机自启有勾表示已开启；再次点击关闭。操作后桌宠会提示结果。
- 如果开启鼠标穿透后无法点击桌宠，从托盘取消鼠标穿透即可。

ChatGPT 联动在“桌宠设置 → 自动化与联动 → ChatGPT 工作状态”开启。
请自行打开 ChatGPT 桌面端；桌宠读取本机 Work/Codex 工作状态，显示工作与完成反馈。
