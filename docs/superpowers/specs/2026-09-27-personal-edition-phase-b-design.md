## 方案选择

1. **按依赖关系完整退役（采用）**：先锁定旧配置与菜单行为，再断开运行入口，清理专属实现。一次交付即可验证前后台都停止，改动涉及多个模块，需要全量回归。
2. 仅隐藏菜单和设置：改动较少，但隐藏的定时器、Agent 消费查询和旧配置仍可继续执行，不满足目标。
3. 先全局禁用，下一轮删实现：降低单轮编辑量，但产生临时死代码和双重迁移；本批已有 9 月 27 日可恢复基线，收益有限。

## 组件和数据流

### 菜单与托盘



`pet/context_menus/quick_launch.py` 的内置“默认浏览器”实际上固定打开 Google。本批移除该默认项，并从旧快捷启动列表中过滤 `kind=default_browser`；保留用户明确指定路径的应用快捷项。若用户要打开某个网页，后续“快捷网址”提供显式地址管理。空快捷启动列表沿用现有占位行为，不因移除默认项而变成无法编辑。

`tools_help` 当前还包含 `harness`。本批保留该入口；下一批拆除 DSH/Harness 后，连同空的 `tools_help` 一并移除。不得因清理空菜单的通用规则改变其他自定义子菜单。旧版菜单的手工路径和模板路径都需覆盖。

### 配置与设置

退役键包括 `agent_cost_enabled`、`click_show_balance`、`balance_refresh_minutes`、`balance_tier_labels_mode`、`balance_tier_label_peak`、`balance_tier_label_idle`、`balance_tier_color_enabled`，以及灵动岛的 `info_mode=balance_tier|balance`。这些键不再进入默认配置或运行时功能判断；加载旧配置时，余额专属显示模式降级到 `time`，其他灵动岛配置和用户数据保持。旧文件不在加载时强制覆写；下一次正常保存时清理已退役键。对外提供明确迁移行为，使反复加载/保存幂等。

设置页移除消费、余额刷新/峰谷标签和点击查余额控件、搜索项与保存分支。保留通用点击交互和通用聊天/识屏 Provider；已有 API 密钥、对话历史、自定义网址/Provider 不迁移到新端点，也不因本批被删除。`balance_cache.json` 历史文件不在本批自动删除，停止读写后由后续目录清理批次盘点。

### 运行与生命周期

`pet/app.py` 不再创建或启动余额刷新 `QTimer`、余额/更新工作线程与桥接对象，不再连接灵动岛展开到静默余额查询。移除窗口的余额/更新回调和点击余额分支；停止 `pet/agent_link.py` 中消费差额跟踪及其查询线程，但保留 Cursor 与其他尚未退役的联动。保留灵动岛通用状态、时间与事件显示，删除余额专属卡片和峰谷定时器。余额查询与更新请求的调用方全部断开后，删除 `pet/balance.py`、`pet/agent_cost.py`、`pet/updater.py` 及零调用的专属资源；应用本地版本由现有 `pet.__version__` 提供，不再通过 updater 取得。





## 失败处理与可恢复性

旧布局引用未知动作时，渲染与编辑预览均忽略它；保留动作仍可打开，设置和退出入口可达。配置字段类型错误、旧余额模式或多次迁移都回退到安全默认值，不触发网络。删除模块前做静态导入与打包资源检查；若仍有保留消费者，先解依赖再删除，不能留下启动时导入错误。依据[批次 A 基线](../../PR-REPORT-PERSONAL-PHASE-A-2026-09-27.md)回滚源码时，不自动覆盖其后更新过的用户配置。

## 测试和验收

每个行为切片先写会在旧实现上失败的测试：新旧配置和重复保存；带退役 ID 的自定义布局；默认/旧版/托盘菜单；旧 `default_browser` 快捷项被移除但应用路径快捷项保留；设置搜索与保存；灵动岛旧模式；Agent 完成事件不查余额；应用启动/退出不创建退役定时器或请求。网络边界用拒绝调用的测试替身，Qt 菜单与生命周期用真实事件循环；不以全文字符串搜索单独代替行为验收。

聚焦测试通过后，按 `AGENTS.md` 运行 Ruff、全量 Python 测试、相关 Qt/线程时序族三遍；受影响打包时检查构建产物与资源清单。实机退出旧桌宠进程，启动新构建 EXE，记录路径及 SHA-256，核对右键菜单、设置搜索、托盘、灵动岛和空闲网络行为。报告逐文件列修改原因和增删行数，测量启动后线程/定时器数、空闲 CPU/内存与被移除请求的触发次数。没有实测的跨平台结果单独标记未验证。

## 范围与后续接口

本批不实现快捷网址、ChatGPT 状态联动或完整图标补齐。快捷网址将在后续批次独立采用空列表默认值；批次 A 的 ChatGPT 探针未找到可靠完成事件，不能借本批的菜单改动启用状态联动。下一批联动拆除须以本批已去除的消费依赖为前提，并负责处理外部 hook/插件和最后的 `tools_help` 空态。
