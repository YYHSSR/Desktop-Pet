# 鲸鱼娘开发交接（2026-10-04）

当前应用是静音桌宠与本机 ChatGPT Work/Codex 状态联动。角色资源、交互动画、物理碰撞和工作提醒是运行路径；内置 AI 对话、识屏、声音、灵动岛、待办与菜单编辑器已移除。旧功能计划和重复历史报告可从 Git 历史查询。

## 运行和目录

- 使用 Python 3.10–3.13，安装根目录 requirements.txt；开发工具见 requirements-dev.txt。
- `python -m pet` 启动桌宠，`python -m pet --settings` 打开独立设置。
- `pet/` 是应用实现，`assets/characters/` 是成套角色动画，`C++-Python/` 是原生碰撞源码，`pet/native/_bin/` 是随包原生库。
- `scripts/` 保存打包、诊断和截图工具，`tests/` 保存现有行为的回归；构建临时目录不提交。

## 设置和入口

托盘负责显示/隐藏、鼠标穿透、开机自启和退出；右键负责动画、角色、大小、速度及快捷操作，并保留“请点击”回应首行。设置负责详细偏好，不复制托盘和右键已有选项。行为重复检测使用内置阈值，不要求玩家配置 W6/W10。

气泡锚定稳定角色主体，默认距离8逻辑像素、字号14像素；ChatGPT普通联动气泡较原来延长2秒。审批/提问等持续提醒保持自己的生命周期，不应被普通气泡覆盖。

## 线程和生命周期

Qt控件只在GUI线程使用；QLocalServer/QLocalSocket与IPC定时器属于碰撞worker。碰撞会话按“停止生产→发送leave→关端点和定时器→退出并等待线程”收口。共享解码与碰撞IPC分离，单窗关闭只释放自己的订阅，进程退出才停止共享源。

联动读取本机增量日志，不开启ChatGPT、不提交审批、不发送用户回答。协议、文件读取上限及字段规则见[联动说明](AGENT_LINK_PROTOCOL.md)。

## 本地验证和打包

```powershell
$env:QT_QPA_PLATFORM='offscreen'
python -m ruff check .
python -m pytest -q
```

行为修复先在公开Qt或模型接口验证失败，再修到通过。配置、IPC、生命周期及跨域改动要跑全量。推送前对受影响时序族按AGENTS要求进行三轮CPU高负载复跑；截图用Windows原生Qt，不能把offscreen或平台替身当作实机证据。

便携包命令与资源校验见[打包流程](ONEDIR_PACKAGING.md)。旧onefile稳定产物继续按[冻结记录](STABLE_BUILDS.md)保护；当前开发输出保留历史webm-chat文件名，以兼容已有配置和自启项。
